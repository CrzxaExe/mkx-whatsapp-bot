# MKx Whatsapp Bot

A Whatsapp automation for handling some task easier

## Requirement

- Bun v1.3.9
- FFmpeg latest (optional)

## Installations

- Use git cloning or download this repo zip and place whatever you want
- Open VS code terminal or your machine terminal
- Run `bun install`
- After installing you can run with `bun start` or `bun dev`
- If bot not login on your WA number, there is qr code to scan it on your WA app

## Configuration

You can configure bot setting on settings.json
